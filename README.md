# E-tecon as an App

## Introduction
> E-tecon is an application that helps to optimize job opportunities for teachers that are seeking employment and Schools that need to select from the pool of available qualified teachers

## Stack Used
- Vites and Next JS for Frontend
- Firebase for backend, datababse and message management
- Sonner for Notification managemnent
- Tailwind for styling
- React Library for Components builiding and sub libraries for Routing
- React Context API for state management
